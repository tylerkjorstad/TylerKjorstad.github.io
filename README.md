# tylerkjorstad.com

Personal website for Tyler Kjorstad — educator, economist, and endurance athlete.

## Stack

Plain HTML + CSS, no build step. Hosted on GitHub Pages with a custom domain.

## Structure

```
index.html          Landing page
passions.html       Outdoor passions + race reviews
professional.html   Teaching, work, accolades
books.html          Book recommendations
contours.svg        Topographic background (Happy Jack synthetic)
CNAME               GitHub Pages custom domain
/images             Photo assets
```

## Local preview

Open any `.html` file directly in a browser. No server needed.

## Editing

All pages use plain HTML and an embedded `<style>` block. Each page is
heavily annotated with HTML comments — search for `Replace` or `To add`
to find spots designed for customization.
